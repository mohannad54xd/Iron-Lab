# Scientific content and source notes

This project keeps a strict distinction between verified source content and placeholder material needed for the experience before the supply PDF is fully translated into structured data.

## Verified from the teacher’s iron mind map

- Siderite: FeCO3
- Limonite: Fe2O3·3H2O
- Magnetite: Fe3O4
- Hematite: Fe2O3
- FeO appears as an iron oxide intermediate in the reaction flow
- The crushing concept demonstrates that mass remains the same while particle size decreases
- The extraction process includes roasting, reduction, and iron formation as sequence steps
- The four iron ores listed for identification are Hematite (Fe2O3), Magnetite (Fe3O4), Limonite (Fe2O3·3H2O), and Siderite (FeCO3)
- Roasting is described as strongly heating ore in air/O2
- Magnetite roasting: 2Fe3O4 + 1/2O2 -> 3Fe2O3; solid mass increases and then becomes constant
- Limonite roasting: 2Fe2O3·3H2O -> 2Fe2O3 + 3H2O; solid mass decreases and then becomes constant
- Siderite roasting: FeCO3 -> FeO + CO2, followed by 2FeO + 1/2O2 -> Fe2O3; solid mass decreases to a minimum, increases, and then becomes constant
- Hematite is listed as Fe2O3, but the supplied sheet gives no distinct hematite roasting equation or hematite-specific mass observation. The app must show this source gap instead of inventing a reaction.
- The reduction-route brief supplies the blast-furnace sequence C + O2 -> CO2, CO2 + C -> 2CO, Fe2O3 + 3CO -> 2Fe + 3CO2, CaCO3 -> CaO + CO2, and CaO + SiO2 -> CaSiO3.
- The supplied reduction-route brief gives MIDREX reforming as 2CH4 + CO2 -> 3CO + 2H2 and oxide reduction as Fe2O3 + 3CO + 3H2 -> 2Fe + 3CO2 + 3H2O. Temperature details not legible/specified remain unassigned.
